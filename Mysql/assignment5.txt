Q1.write an sql query to list all books written by author 'loni' with price less than 600.
-> mysql> select * from book
    -> where author_name = 'loni' and cost < 600;

Q2.write an sql query to display issue details of books that are not returned yet.
-> mysql> select * from issue_details
    -> where return_date is null;

Q3.write an sql query to update all blank return_date values to '2025-12-31' excluding issue ids 7005 and 7006.
-> mysql> update issue_details
    -> set return_date = '2025-12-31'
    -> where return_date is null
    -> and lib_issue_id not in (7005,7006);

Q4.write an sql query to display issue details of books issued for more than 30 days.
-> mysql> select * from issue_details
    -> where datediff(curdate(),issue_date) > 30;

Q5.write an sql query to list all books priced between 500 and 750 and belonging to category database.
-> mysql> select * from book
    -> where cost between 500 and 750
    -> and category = 'database';

Q6. write an sql query to list all books belonging to categories science,database,fiction or management.
-> mysql> select * from book
    -> where category in ( 'science','database','fiction','management');

Q7. write an sql query to list all members in descending order of penalty amount.
-> mysql> select * from member

Q10. write an sql query to list all books whose name contains the word 'sql'.

Q11.write an sql query to display lib_issue_id,issue_date,return_date and number of days the book was issued.
->  select lib_issue_id,issue_date,return_date,
    -> datediff(ifnull(return_date,curdate()),issue_date)
    -> as Days_issued
    -> from issue_details;

Q21.write an sql query to display member id's who have issued more than 2 books

Q22.write an sql query to display member_id,book_no and number of times the same book was issued by that member.
-> mysql> select member_id,book_no,count(*) from issue_details

Q23.write an sql query to display month wise count of books issued,sorted by count descending.
-> mysql> select monthname(issue_date) as month,count(*) as Issue_count from issue_details
    -> group by month
    -> order by issue_count desc;
